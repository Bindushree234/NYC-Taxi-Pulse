# The Pulse of the City – NYC Taxi Analysis

## Objective
Analyze NYC taxi system to detect stability, patterns, and inefficiencies.

## Steps Performed
- Data cleaning and validation
- Hypothesis testing (passenger behavior)
- Time-based aggregation (daily, hourly)
- Policy simulation
- Power BI dashboard visualization

## Key Insights
- Taxi demand follows structured daily patterns
- Behavioral variations exist across hours
- System shows both stability and noise
- Policy impact depends on demand sensitivity

## Conclusion
The system is not failing but is not perfectly stable. 
Some patterns are real, while others may be artifacts of observation.
